# Muse Skill Packs — Lite Previews

Free lite previews of the Muse skill packs by Bupz Nguyen. Each folder below is one pack: an overview README plus lite editions of its skills (core principles and workflow outlines only).

The full versions — complete checklists, prompt libraries, templates, references and scripts — are available on Agensi: https://www.agensi.io/users/bupz-nguyen

Packs in this repo:
- pinterest/ — Pinterest Growth System, 5 skills
- video-drama/ — AI Video & Short Drama, 16 skills
- character-consistency/ — Character Consistency, 9 skills

The Money Channels lite pack (YouTube, Facebook, TikTok, X) lives in the muse-skills-kiem-tien repo.
