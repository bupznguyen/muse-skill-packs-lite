# model-selector

A "shopping advisor" for 15 mainstream AI video models (11 commercial + 4 open source). Ask the user 3-4 key questions, then give a recommendation + the reasoning behind it.

*Source: https://github.com/cclank/lanshu-awesome-ai-video-kit (MIT)*

## When not to use this skill

If the user has already decided on a model, use that model's prompter skill; if they ask how to write a prompt, use a prompter skill; if their prompt isn't working, use the Seedance debugger.

## Capability quick-reference matrix for the 11 models

The full version carries a star-rated matrix comparing the models on Chinese-language ability, audio, physics, editing, duration, open-source status, and availability in China — covering Seedance 2.0, HappyHorse 1.0, Kling 3.0, Sora 2, Veo 3.1, Gemini Omni, Runway Gen-4, Pika 2.5, Hailuo 02, Hunyuan 1.5, Wan 2.7, and Jimeng 3.0, each with what it is best at.

## Workflow

Ask 3–4 key questions (duration, audio, language, editing vs. generating, platform limits, use case — picking only the ones that most affect the outcome), then walk a decision tree that routes editing, digital-human lip-sync, multi-person dialogue, Chinese-language drama, extreme physics, creative effects, local/open-source deployment, cinematic quality, compact clips, and multi-shot narrative to the fitting model, and output the recommendation in the standard format.

## Worked examples

The full version works through three recommendations in detail: a Chinese short drama, restyling an existing video into watercolor animation, and setting up local video generation on a limited budget with LoRA training.
