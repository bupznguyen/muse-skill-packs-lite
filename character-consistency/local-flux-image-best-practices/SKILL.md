# FLUX Best Practices

Use this skill when generating prompts for any BFL FLUX model to ensure optimal image quality and accurate prompt interpretation.

## When to Use

Prompting FLUX.2 or FLUX.1 for text-to-image, image-to-image, JSON scenes, typography, multi-reference, and brand work.

## Quick Reference

Build prompts as subject + action/pose + style/medium + context/setting + lighting + camera/technical, in natural, specific prose. No negative prompts; specify lighting, quote text to render, use hex colors with a description, and pick the model by speed, quality, typography, or editing need.
