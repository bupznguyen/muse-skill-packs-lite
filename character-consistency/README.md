# Character & Image Consistency Pack — 9 Skills for Muse (Lite Preview)

> **This is a free lite preview.** Each skill folder contains an overview SKILL.md — the core principle and workflow outline — so you can see exactly how the pack works before buying. The complete skills are in the paid full version (see the bottom of this page).

Nine skills that work together to lock a character's identity across every generated shot — and take the image all the way to delivery quality. The first group locks character identity from the brief stage through drift checking; the second generates and edits images with Gemini, Seedream and FLUX models; the last group fixes the "plastic AI look", upscales to delivery resolution, and writes portraits from a proven prompt pattern.

## The 9 skills

### Lock character consistency

- **local_character_consistency** — The hub skill: separates hard-locked identity anchors (face and jaw shape, eyes, nose and mouth proportions, age range, skin tone, hairline, signature features, body proportions) from narrative variables, builds a close-up and a three-panel character sheet, and checks every new generation for drift in a fixed order.
- **local-geying-character** — A two-layer Character DNA model (locked anchors vs. per-shot variables) with turnaround, expression and outfit rules, a storyboard prompt template, and a continuity checklist for storyboards, keyframes and long series.
- **local-nigo-character-consistency** — Expands a short brief into ultra-detailed prompts, because vague prompts produce generic faces and a generic face cannot stay consistent. Produces the close-up prompt, the three-panel sheet prompt, and the "role line" you carry into every later prompt.

### Generate and edit images with models

- **local-banana** — Generates and edits images with Gemini image models: turns intent into a frozen visual brief, compiles the exact prompt, shows a plan with disclosed cost for approval, executes through the bundled Gemini client, and inspects the actual pixels.
- **local-doubao-seedream-image** — Generation and editing via Volcano Ark with Seedream 5.0 Pro, 5.0 Lite, 4.5 and 4.0: character reference portraits for Seedance video, image sets, storyboards and comic panels, and multi-reference fusion.
- **local-flux-image-best-practices** — Prompting guide for BFL FLUX models: the prompt formula (subject, action, style, context, lighting, camera), hex color prompting, typography in quotes, structured JSON prompting, and multi-reference editing limits per model.

### Fix defects and raise quality

- **local-ai-image-realism** — A seven-step repair workflow for the most visible AI defect in an existing image — plastic skin, malformed hands or faces, extra fingers, repeated textures, inconsistent lighting — diagnosing one priority problem and picking the smallest useful repair.
- **local-image-upscaler** — Upscales AI keyframes and posters with Real-ESRGAN x4plus on plain CPU via ONNX Runtime, with tiled inference and Hann-window blending so no seams appear; a 576×1024 keyframe becomes a 2304×4096 master you can crop to 1080×1920 for TikTok, Reels and Shorts.
- **local-oriental-fantasy-portrait** — A 9-block prompt pattern distilled from two production prompts: exact costume color palettes, liquid-silk fabric physics, precise per-limb poses, material-contrast hair and accessories, and a non-negotiable real-skin face lock.
