# Geying Character

Geying Character is an Agent Skill for **production character continuity**.

The goal is not to make every image visually identical. The goal is to keep the identity stable while the story changes.

## Core model: Character DNA

Locked identity anchors (face, eyes, proportions, age, skin tone, hairline, hairstyle, signature features) stay stable; narrative variables (expression, pose, wardrobe, camera, scene, lighting) may change by shot. Never change a locked anchor for a narrative change.

## Workflow

Extract Character DNA, mark attributes `locked`, `preferred`, or `variable`, establish a canonical reference first, then build variants and shots from that DNA and report drift.

## Character DNA output

Produce a compact record in concrete visual language: identity attributes, locks, and variables.

## Turnaround rules

Preserve hair silhouette, proportions, and signature-detail side, with neutral lighting and no extra decorations.

## Expression rules

Change brows, eyelids, mouth, cheek tension, and head tilt only — not face shape, eye spacing, or age.

## Outfit rules

Keep face, hair, age, proportions, and markings; change only requested clothing and context.

## Storyboard / keyframe prompt pattern

Locked Character DNA first, then shot, expression, outfit, scene, and continuity rules.

## Drift check

Compare geometry, eyes, hairstyle, age, signature detail, and proportion to the canonical reference; classify drift as `none`, `minor`, `material`, or `redesign`.

## Video continuity

Carry the same anchors into first frame, last frame, and motion description, prioritizing identity reference.

## Delivery

Return generated assets when a tool is available; otherwise return DNA, shot prompt, continuity constraints, and reference usage.
