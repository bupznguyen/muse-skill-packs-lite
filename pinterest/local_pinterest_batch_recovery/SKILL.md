# Recover an Unscheduled Pinterest Batch

## Checkpoint the batch before scheduling

Write the pin copy file first — every pin with title, board, destination link, image file and intended date — and mark the batch in the channel progress file as built but not scheduled. The progress file is the record of truth, never a chat message or a run report.

## Resume an unscheduled batch first

At the start of every weekly run, check the progress file and schedule any built-but-unscheduled batch before building a new theme. Check the Scheduled Pins page before each pin and skip pins already there. Re-date passed pins to the next free day at 09:00 AM local time; ask the user before dropping any built pin.

## Schedule safely and report the result

Carry the exact approved copy, image and time into the scheduling task; verify the displayed time after each save. If Pinterest blocks access or the session drops, stop at once and do not retry in the same run. Report what is built, scheduled and still waiting, then update the progress file with dates and links.
