# Pinterest Growth

## Priority order
search visibility → saves → outbound clicks → conversion. Sustainable growth; never burn a new channel.

## Core principles
- Search intent matters more than keyword count.
- Keywords appear naturally in the profile, boards, titles, descriptions and landing pages. No stuffing.
- Every pin serves exactly **one** intent (Inspire, Learn, Compare, Plan or Shop).
- Prioritize fresh creative, useful content, save-worthy pins, and a CTA that fits.
- Never fabricate search volume or trend data when you don't have real data.

## The 8-phase workflow

### 1. Positioning
One positioning statement, 3–6 content pillars, 1–3 audience segments, the main search intents, and the off-niche content to avoid.

### 2. Keyword Map (5 tiers)
A 5-tier map (core → mid-tail → long-tail → problem/solution → seasonal); every keyword tagged with intent, pillar, board, angle and landing page.

### 3. Board Architecture
5–12 core boards for a new channel, each with a purpose, a primary keyword and supporting keywords; titles follow `[Keyword] Ideas`, ≤50 characters.

### 4. Pin Package
Spec every pin before production: intent, keywords, title, description, board, overlay, brief, alt text, CTA, URL, 3 headline variants, AI disclosure — using the pack's title and description frameworks.

### 5. Creative System
2:3 vertical (1000×1500), mobile-first, one focal point, short readable overlay, light brand cue — no clickbait promises.

### 6. Publishing Plan
Mix evergreen, seasonal and experimental pins; 1–3 fresh pins/day for new channels; seasonal 45–60 days early. Fresh = new visual or angle, not a new caption.

### 7. Analytics Loop
Diagnose with a symptom → cause → fix matrix. Target save rate ≥ 0.8% (home-goods benchmark); never judge a channel in its first month.

### 8. Iteration 20/60/20
Keep the best 20% of patterns, improve 60%, replace the weakest 20%. A winning angle gets 3 variants.

## Operating rules (from hands-on channel operations)
- The scheduler reads times in **the timezone shown on the account** — always verify the displayed time after saving.
- Turn on "Mark as AI-Modified" for every AI-image pin; name image files with keywords; write alt text on every pin.
- Affiliate: `#affiliate` in the description · never state a fixed price · roughly a 70/30 content/affiliate ratio · never click or buy your own links.
- Use only the native scheduler / Tailwind / the official API. No obscure URL shorteners, no VPN country-hopping.
- Publish in the language of your target audience, at that audience's peak hours.
