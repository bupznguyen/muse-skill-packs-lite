# Pinterest Growth System for Muse — SEO, Pin Design, Analytics (5 Skills) · Lite Preview

> This GitHub version is a **free lite preview** of the paid Pinterest pack. Each skill is included as an overview edition: the core principles and the workflow outline are here, while the detailed checklists, complete templates, reference files and worked examples are only in the full version.

Turn Muse into the operating system for your Pinterest channel. The five skills run a Pinterest channel end-to-end — positioning, keyword research, board architecture, pin production, publishing, analytics and iteration — using workflows distilled from real channel operations.

## The 5 skills

- **pinterest-growth** — the core operating system: an 8-phase workflow (Positioning → Keyword Map → Board Architecture → Pin Package → Creative System → Publishing → Analytics → Iteration), a 5-intent taxonomy so every pin has one clear job, and a 20/60/20 iteration loop.
- **pinterest-seo** — the keyword layer, built on the FOUND framework: research real queries with autocomplete, Guided Search and Pinterest Trends (never fabricated volumes), and align Pin → Board → Page across Pinterest's ranking signals.
- **pinterest-pin-design** — the visual layer, built on the SAVED framework: 2:3 (1000×1500) pins with one focal point and a keyword overlay that reads at feed size, plus 3–5 genuinely fresh variants per destination URL.
- **pinterest-analytics** — turn CSV exports, PDF reports or dashboard screenshots into top-performer rankings, trend reads with seasonality context, and specific next-content decisions.
- **local_pinterest_batch_recovery** — the safety net for weekly production: checkpoint every built batch, resume an unscheduled batch before starting a new theme, re-date passed slots, and report exactly what is still waiting.

## How to use this preview

Copy a skill folder into your Muse custom-skills directory and ask Muse to work through that skill's workflow with you. The lite SKILL.md files give Muse the principles and the shape of each workflow — enough to plan a channel, structure a keyword map or brief a pin.
