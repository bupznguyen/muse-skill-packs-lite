# pinterest-pin-design

A **design-craft skill** — design the pin's concept, composition and overlay, produce the **brief**, and plan the **fresh-pin variants**. The agent designs + briefs + critiques; a human or an image/design tool creates the final raster. Read **brand-profile**, the **destination**, and the keyword from **pinterest-seo** first.

## The POV: a search result, not a post
A pin is a search result in a two-column mobile feed, competing at ~half a phone screen wide; its job is the **save and the outbound click**, and it keeps working for months — an **asset, not a post**. The visual and the keyword are one unit (the keyword goes in the overlay AND the title), and fresh beats reposting: a fresh pin is a new image/layout/overlay for the same URL, not a repin. Design mobile-first, always in **2:3 (1000×1500)** — other ratios are penalized.

## The framework: SAVED
- **S — Stop the scroll on a 2:3 canvas:** 1000×1500, one focal point; lifestyle/in-context imagery beats product-on-white; parseable at feed size.
- **A — Anchor the keyword overlay:** the pinterest-seo keyword large on the image (Pinterest OCR-reads it); ≤~6 words, bold, high contrast, top-third or center; not a caption duplicate.
- **V — Visual brand system:** a consistent template family (fonts/palette/layout); subtle logo/URL, **never bottom-right** — Pinterest's icons overlay that corner.
- **E — Every URL gets fresh variants:** 3–5 **visually distinct** designs per destination (new image + layout + overlay angle — not a color swap).
- **D — Decide the format + hand off:** static = traffic workhorse; video (9:16, 6–15s) = engagement; multi-slide = awareness.

## Honest scope (never violate)
- The agent designs and briefs — a **human or an image/design tool creates the final raster**.
- **No misleading pins** — the visual must promise what the page delivers (Pin → Board → Page must match). **No repin-as-fresh dupes.** **Disclose AI imagery.** **Never fabricate saves, clicks or impressions.**

## Operating rules (pack amendments — these override any third-party tooling mentioned elsewhere)
- Publish/schedule only with the Pinterest native scheduler, Tailwind, or the official Pinterest API v5.
- Every AI-image pin: turn on "Mark as AI-Modified". Overlay text ≤8 words, in the sky/upper area, never covering the subject. Standard size: 1000×1500 (2:3).
